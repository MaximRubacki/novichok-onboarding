# Пульт адаптации новичков

Тестовое задание, слово «НОВИЧОК». Новичок понят как сотрудник в первые 90 дней: по условию каждый третий из ушедших не доработал до трёх месяцев. Инструмент для руководителей и HR: кто из новичков сейчас в зоне риска и что сделать сегодня.

## Запуск
Один файл `novichok.html`, без сборки и зависимостей. Откройте его в браузере. Кнопка «Подготовить разговор» использует ИИ только внутри claude.ai (там спросит разрешение), в обычном браузере подставляется шаблон по тем же причинам риска.

## Что умеет
- Список новичков с баллом риска, фильтр по роли, поиск по ID или имени, фильтр «только высокий».
- Причины риска и действия по каждому человеку, отметка «сделано», сводка «Что сделать сегодня».
- План на 90 дней по роли (склад, магазин, продажи, офис) с контрольными точками на 3, 14, 30, 60, 90-й день.
- Подготовка разговора: план для руководителя и сообщение новичку (ИИ или шаблон), кнопка «Копировать».
- Блок «Насколько можно доверять баллу» и кнопка «Проверить правила» (6 проверок расчёта).
- Выгрузка текущих данных в CSV.

## Как считается риск
Правила в функции `risk()`: нет наставника +25; каждая пропущенная контрольная точка +20 (максимум 40); 3 и более просроченных задач +20, 1–2 +8; оценка руководителя 1–2 из 5 +25; нет оценки после 14-го дня +10; склад и магазин +5. Высокий риск от 50, средний от 25. ИИ баллы не считает.

## Данные
Полностью синтетические (генератор с фиксированным seed 2026 в начале скрипта): 36 текущих новичков и история из 140 человек с известным исходом. Реальных людей нет, имена выдуманы.

## Ограничения
- Данные сгенерированы по тем же идеям, что и правила, поэтому блок проверки доказывает работу механики, а не качество на реальных людях.
- Интеграции с Битрикс24 нет. Веса не подбирались по реальным уходам.
- План на 90 дней статичный по ролям, ИИ его не адаптирует.
- Состояние «сделано» живёт только в открытой странице.
